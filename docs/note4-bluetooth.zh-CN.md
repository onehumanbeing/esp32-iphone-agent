# Zectrix Note 4 蓝牙键鼠

Note 4 是带电池的 4.2 英寸黑白墨水屏设备，主控为 ESP32-S3。本固件将它用作 iPhone 的蓝牙键鼠。项目默认 XIAO ESP32S3 同样通过蓝牙接收 App 指令，但键鼠输入通过 USB 线送回手机。

Note 4 可以分别供电，通过蓝牙接收 App 的指令，再作为辅助触控的鼠标和键盘向同一台 iPhone 输入。屏幕画面沿用项目的 AirPlay 与 Wi-Fi 配置。App 的最低系统版本为 iOS 18。

## 构建板端固件

在仓库根目录运行以下命令。第一条为 16 MB Flash、OPI PSRAM 的 Note 4 构建镜像，产物位于 `hardware/build/note4/`。第二条编译标准 8 MB USB 版本，产物位于 `hardware/build/`。

```sh
hardware/flash.sh --note4 --build-only
hardware/flash.sh --build-only
```

Note 4 首次部署使用有线方式，部署前需核对实物板型、完整 Flash 备份和分区表。本候选版本的脚本只为 Note 4 编译镜像。项目网页刷机入口和 App 的 USB 固件更新仅供标准板使用。

## 连接和检查

1. 给已装 Note 4 固件的板子上电，在配对窗口内用 App 连接名为 `ESP32 Agent …` 的开发板，在 iOS 完成蓝牙配对。配对窗口在上电或板端清除配对后开放三分钟。
2. 在 iPhone 的“设置 → 辅助功能 → 触控 → 辅助触控”开启辅助触控。在“设备”中找到同一块板，将鼠标按钮 2 映射为“主屏幕”，供返回桌面的操作使用。
3. 在 App 诊断页查看蓝牙输入状态。若命令通道已连、指针仍未就绪，先检查辅助触控和上述设备配对。选择现有校准流程，观察指针实际移动、检查点触发，再开始任务。
4. 需要查看画面时，按[快速开始](../README.zh-CN.md#快速开始)设置板子网络和 AirPlay 镜像。

从旧实验固件升级时，新固件沿用上游的 App 蓝牙地址。若 iOS 仍显示旧配对，请先在系统设置中忽略旧设备，再给板子上电，在新配对窗口内重新配对并完成校准。

板端 `status` 中的 `board: note4` 标明板型，`hid: ok` 表示蓝牙输入链路就绪。核对点击时，应以手机上的实际触点或界面变化作为证据。
